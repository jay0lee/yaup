Version Tracking & Re-signing Enforcement

Whenever you increment the version string, all users will be prompted to re-sign upon their next browsing session.

Set to 0 to never expire (valid until version is incremented). Set to 30, 90, or 365 for periodic re-acceptance.

Google Workspace Admin Console Instructions

  1. Open admin.google.com and navigate to Devices > Chrome > Apps & extensions > Users & browsers.
  2. Find or add YAUP using its Extension ID and the update URL: https://jay0lee.github.io/yaup/hosted/update.xml
  3. Set Installation Policy to Force install.
  4. Under Policy for extensions, upload the exported yaup-policy.json or paste the JSON text.
  5. Click Save. Chrome will push the policy to all managed profiles and browsers!
